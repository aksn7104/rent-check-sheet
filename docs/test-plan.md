# テスト設計（判定ルールの検証ケース）

要件定義 `docs/requirements.md` の判定ルール R-01〜R-13 を、1件ずつ検証する。判定は `src/logic.js` の関数として実装し、`tests/run-tests.js` を Node.js で実行して確認する。

## 前提

- 金額は円の整数。日付は `YYYY-MM-DD`。基準日（今日）はテストごとに指定する。
- 判定の出力：`status`（PAID／PARTIAL／OVERPAID／UNPAID）、`level`（NONE／YELLOW／RED）、`overdueDays`、`shortage`（不足額）、`excess`（超過額）。
- 設定の初期値：黄の開始 1日、赤の開始 7日（超過日数が7日を超えたら赤）、更新期限は黄 90日・赤 30日。
