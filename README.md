# 家賃入金チェック表（rent-check-sheet）

小規模の個人大家さん向けの、家賃の入金と物件の管理表です。
Google スプレッドシート（Excel でも可）の計算式だけで動き、マクロやプログラムの実行は必要ありません。

> **ご注意**
> 判定は、入力した記録にもとづく目安です。導入後の最初の数か月は、通帳や銀行の明細と必ず突き合わせて確認してください。
> 年間収支、予定年間収支、固定資産税の推定、空室損失、家賃改定の試算は参考値です。税金や会計の扱いは、税務署や税理士に確認してください。
> 同梱のサンプルデータ（入居者、物件、保証会社など）はすべて架空です。

## できること

| 分類 | シート | 内容 |
|---|---|---|
| 入金 | 入金チェック | 対象の年・月の入金状態（入金済・一部入金・未入金・期日前・過入金）、不足額、滞納の黄・赤 |
| 入金 | 入金記録・請求調整 | 分割入金、保証会社からの入金、退去月の日割りなど、その月だけの請求額 |
| 保証会社 | 入金チェック・保証会社入金 | 一般保証型の事故報告の期限、支払委託型の振込と割り当て合計の差 |
| 期限 | 期限管理 | 契約更新、火災保険、保証会社の契約の残り日数 |
| 物件 | 物件台帳 | 物件ごとの戸数・家賃の集計、固定資産税・都市計画税の推定、表面利回り |
| 敷金 | 敷金台帳 | 預り金、控除、返還額、追加請求額、精算の遅れ |
| 空室 | 空室・募集 | 空室日数、空室率、空室損失（概算） |
| 設備 | 修繕履歴 | 工事・交換の履歴、次回の交換の目安 |
| 税 | 税カレンダー | 固定資産税などの納期限、納付状況、納付予定額 |
| 家賃 | 家賃改定試算 | 改定案の増減額と、退去の見込みを含めた年間の影響額 |
| 収支 | 年間収支 | 月別の実績（家賃収入・修繕費・税・経費）と、保有物件にもとづく予定年間収支 |
| 全体 | ダッシュボード | 各シートの集計を1画面で表示 |

- 契約は100件、物件は20件、入金記録は3,000行まで入力できます。
- 滞納・期限の日数、税率、住宅用地の特例の割合などは「設定」シートで変更できます。
- 固定資産税は、税カレンダーに入力した額を優先し、入力がない物件だけ推定額を使います。

## 使い方

1. `rent-check-sheet-manual.xlsx` をダウンロードし、Google ドライブにアップロードして Google スプレッドシートで開きます（Excel でも開けます）。
2. 「使い方」シートの「はじめの5ステップ」に沿って、設定、台帳、入金記録の順に入力します。
3. 黄色の背景・青い文字のセルだけを書き換えます。灰色のセルは計算式です。

### 税制・法制が変わったとき

1. 総務省・国税庁・自治体の発表や納税通知書で、変更の内容を確かめます。
2. 「設定」シートの⑩「税制・法制の値」を書き換えます（税率は％、割合は `=1/6` の形）。
3. 同じ行の「確認日・出典（メモ）」に、書き換えた日と根拠を書きます。
4. 物件台帳の税の推定と、年間収支の予定年間収支が変わったことを確かめます。
5. 新しい特例など、値で表せない変更は、計算式と判定ロジックの修正が必要です（[要件定義 4.1](docs/requirements.md)）。

## 仕組み

```
docs/requirements.md      要件定義（判定ルール R-01〜R-26）
docs/test-plan.md         テスト設計（T-01〜T-91）
src/logic.js              判定ロジック（JavaScript。Google Apps Script でもそのまま動く書き方）
tests/run-tests.js        判定ロジックの自動テスト
tools/build_template.py   スプレッドシート（.xlsx）を生成する
tools/verify_template.py  スプレッドシートの計算結果を logic.js の結果と突き合わせる
tools/recalc.py           LibreOffice でスプレッドシートを計算させる（突き合わせの前に使う）
```

スプレッドシートの判定は計算式で書かれていますが、同じ判定を `src/logic.js` にも実装しています。
`logic.js` を正解として自動テストで固め、スプレッドシートの計算結果をそれと突き合わせることで、計算式の誤りを見つけます。

```
要件定義（ルール） ─→ テスト設計 ─→ logic.js ＋ 自動テスト
                                        │ 正解として使う
スプレッドシート（計算式） ──── 突き合わせ ─┘
```

### 検証の結果（2026-11-23 時点）

- 判定ロジックの自動テスト：84件すべて成功（T-01〜T-44、T-52〜T-91）
- スプレッドシートと logic.js の突き合わせ：基準日と対象月を変えた5条件で、606項目すべて一致
- 計算式：約20,500個、エラー0（LibreOffice で再計算）
- 税率と特例の割合を書き換えたケースでも、物件台帳の推定税が logic.js と一致

## 開発者向け

必要なもの：

- **Node.js**：判定ロジック（logic.js）とテストを動かすために使います。
- **Python 3 と openpyxl**：スプレッドシートを作るプログラムと、突き合わせのプログラムを動かすために使います。
- **LibreOffice**：無料の表計算ソフトです。プログラムで作ったスプレッドシートには計算式だけが入っていて、計算結果はまだ入っていません。突き合わせの前に、LibreOffice で開いて計算させます（`tools/recalc.py` が自動で行います）。

スプレッドシートを使うだけなら、これらは必要ありません。Google スプレッドシートや Excel で開けば、自動で計算されます。

```bash
# 判定ロジックのテスト
node tests/run-tests.js

# スプレッドシートの生成（設定セルの位置を <出力>.addr.json に書き出す）
python3 tools/build_template.py rent-check-sheet-manual.xlsx

# 突き合わせ（コピーを LibreOffice で計算させ、logic.js の結果と比べる。数分かかる）
RECALC=tools/recalc.py python3 tools/verify_template.py rent-check-sheet-manual.xlsx
```

使う関数は、Google スプレッドシートと Excel の両方で動くもの（SUMIFS、COUNTIFS、INDEX/MATCH、SUMPRODUCT、EDATE、EOMONTH など）に限っています。
